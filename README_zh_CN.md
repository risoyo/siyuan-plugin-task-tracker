# 思源任务追踪插件

任务追踪把思源文档变成可跟踪的任务。你先选择一个文档作为“事项库”根文档，之后每个任务都会创建为事项库下的子文档；子任务会创建为父任务文档的子文档，因此任务层级也会保留在思源文档树中。

[English README](README.md) | [使用说明](docs/USER_GUIDE_zh_CN.md) | [User Guide](docs/USER_GUIDE.md)

## 功能特性

- 任务文档工作流：每个任务都有真实的思源文档、元信息块和自定义属性。
- 支持从顶栏、停靠栏、任务控制面板、当前文档、选中块创建任务。
- 任务字段包括项目、父任务、来源笔记、状态、优先级、创建日期、计划开始/结束、截止日期。
- 任务追踪停靠栏提供全部、焦点、今日三个日常跟踪筛选。
- 任务控制面板提供表格、清单、时间轴、看板、日历、已完成六种视图。
- 日历按计划开始日期展示任务，并可单独展开未安排任务列表。
- 已完成视图按任务创建月份分组。
- 支持在列表中直接修改状态、优先级、计划日期和截止日期。
- 表格列宽可拖拽调整，并会保存到插件设置。
- 启动时会等待思源同步状态，并可在换设备或同步异常后从任务文档属性恢复 `tasks.json`。
- 设置中提供清理已删除任务记录、从事项库重建任务索引等维护工具。

## 使用要求

- 思源 `3.6.4` 或更高版本。
- 支持桌面端、浏览器桌面端和桌面窗口。
- 支持 Windows、Linux、macOS、Docker 以及思源标准后端。

## 快速开始

1. 新建或打开一个文档，例如“事项库”。
2. 在文档标题菜单中选择“将当前文档设为事项库”，或在 `设置 -> 任务追踪 -> 事项库` 中粘贴该文档 ID 后绑定。
3. 从顶栏、停靠栏、任务控制面板、当前文档或选中块创建任务。
4. 打开任务控制面板，在表格、清单、时间轴、看板、日历、已完成视图之间切换管理。
5. 顶层任务完成后，会自动归档到 `事项库/已完成/YYYY-MM`。

## 实现说明

插件会把快速索引保存在 `tasks.json`，把设置保存在 `settings.json`。同时，任务元数据也会写入任务文档的自定义属性，因此在换设备、同步异常或索引丢失后，可以从事项库下的任务文档重建索引。

创建任务时，插件会按设置中的任务模板渲染任务文档。默认模板包含一个引用块，记录来源、父任务、项目、状态、优先级、创建时间、截止时间、计划时间和子任务链接。建议保留这个元信息块，或至少保留一个包含 `来源：` 的引用块，这样在面板里修改任务字段时，插件才能把信息同步回任务文档正文。

在任务控制面板中删除任务，会在确认后删除该任务文档及其所有子任务文档。设置里的“清理已删除任务记录”只会清理那些思源文档已经不存在的插件索引记录。

## 模板占位符

任务模板支持：

`{{title}}`、`{{source}}`、`{{parent}}`、`{{project}}`、`{{status}}`、`{{priority}}`、`{{dueDate}}`、`{{planStart}}`、`{{planEnd}}`、`{{childTasks}}`、`{{childTaskList}}`、`{{createdAt}}`、`{{updatedAt}}`。

## 开发

```bash
npm install
npm run typecheck
npm run build
```

常用脚本：

- `npm run build`：构建发布用插件到 `dist/`。
- `npm run build:local`：构建并同步 `dist/` 到本机思源插件目录。
- `npm run release`：构建并在 `release/` 下生成发布压缩包。
- `npm run dev`：使用 Vite watch 模式开发构建。

如果要在另一台机器上同步到本地思源插件目录，请先设置 `SIYUAN_PLUGIN_DIR`，再执行 `npm run build:local`。
