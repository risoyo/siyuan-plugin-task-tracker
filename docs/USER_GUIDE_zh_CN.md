# 任务追踪使用说明

本文档对应当前插件版本的真实实现，用来说明事项库、任务文档、侧栏、控制面板、模板和维护工具的使用方式。

## 1. 核心概念

- 事项库：一个由你指定的思源文档，用作任务文档的根目录。
- 任务文档：每个任务都是一个真实的思源子文档，位于事项库下，或位于父任务文档下。
- 任务索引：`tasks.json` 是插件用于快速展示的本地索引；任务文档的自定义属性用于恢复索引。
- 来源笔记：任务可以记录创建它的来源文档或来源块，并在任务文档中生成思源块引用。
- 父子任务：子任务会成为父任务文档的子文档，面板中也会按树形结构展示。

## 2. 首次配置事项库

1. 新建一个文档，例如“事项库”。
2. 打开该文档，在文档标题图标菜单中选择“将当前文档设为事项库”。
3. 如果当前文档无法自动识别，可以在思源中复制该文档 ID，打开插件设置，在“事项库”中粘贴 ID 并点击“绑定 ID”。
4. 可选：设置“默认项目”，或按自己的笔记结构修改“任务模板”。

设置完成后，新建任务会创建到事项库下；新建子任务会创建到父任务文档下。

## 3. 创建任务

可以从以下入口创建任务：

- 顶栏任务图标；
- 任务追踪停靠栏；
- 任务控制面板；
- 当前文档标题菜单；
- 当前块或选中块的块菜单；
- 日历视图中的某一天。

任务创建窗口支持填写任务标题、项目、父任务、状态、优先级、创建时间、计划开始、计划结束、截止日期和来源。

来源有两种模式：

- 手动创建：不绑定来源笔记。
- 笔记：绑定来源文档或来源块。从文档菜单或块菜单创建时会自动带入来源。

在日历视图中点击某一天创建任务，会自动把这一天作为计划开始日期。

## 4. 任务追踪停靠栏

停靠栏用于日常快速查看和轻量修改。

- 全部：所有未完成的活跃任务，包括待处理、进行中、等待中。
- 焦点：进行中的任务，或计划/截止日期为今天及以前的活跃任务。
- 今日：计划/截止日期为今天的活跃任务。

停靠栏支持打开任务、修改状态、修改计划日期、修改截止日期、新建任务、打开任务控制面板，以及清理已经删除文档对应的任务记录。

## 5. 任务控制面板

可以从顶栏或停靠栏打开任务控制面板。

视图说明：

- 表格：高密度任务表，可直接编辑状态、优先级、计划日期、截止日期，并支持拖拽调整列宽。
- 清单：树形任务清单，适合逐项推进。
- 时间轴：按计划开始日期分组，未安排任务会排在前面。
- 看板：按任务状态分列展示活跃任务，不包含已完成任务。
- 日历：按计划开始日期展示任务，可展开右侧未安排任务浮层。
- 已完成：按任务创建月份分组展示已完成任务。

搜索会匹配任务标题、项目、来源文本、来源类型、状态、优先级、日期和父任务标题。

常用操作：

- 打开任务文档；
- 打开来源文档；
- 编辑任务；
- 添加子任务；
- 完成或重新打开任务；
- 删除任务树。

在任务控制面板中删除任务时，插件会在确认后删除该任务文档及其所有子任务文档。这个操作不是只删除索引，请谨慎使用。

## 6. 状态、优先级和日期

状态：

- 待处理：还未开始的任务。
- 进行中：当前正在推进的任务。
- 等待中：依赖外部反馈或暂时等待的任务。
- 已完成：已经结束的任务。
- 已取消：不再推进的任务。

优先级：

- 无、低、中、高。

日期规则：

- 创建时间会影响任务文档命名和已完成视图的月份分组。
- 计划开始用于时间轴和日历视图。
- 计划结束会写入任务元信息和模板。
- 截止日期会参与停靠栏的焦点/今日筛选。

## 7. 完成与归档

顶层任务被标记为已完成后，插件会自动把它移动到事项库下的归档目录：

```text
事项库/已完成/YYYY-MM
```

归档月份按任务创建时间计算。父任务移动后，子任务路径也会同步刷新。子任务单独完成时会保持在父任务下，不会单独移动到归档目录。

“已完成”视图会按创建月份分组，可在其中重新打开任务或删除任务。

## 8. 维护与恢复

插件设置中提供两个维护按钮：

- 清理已删除任务记录：检查索引中的任务文档是否还存在，如果文档已经被删除，就移除对应记录。
- 从事项库重建任务索引：扫描事项库下带有任务自定义属性的文档，重建 `tasks.json`。

插件启动时会等待思源同步状态稳定，再执行恢复和同步逻辑。如果索引为空，或发现事项库中有索引缺失的任务文档，会尝试从任务文档属性恢复。这适合换设备、同步异常或索引丢失后的修复。

## 9. 任务模板

默认模板包含一个任务元信息引用块。建议保留这个引用块，或至少保留一个包含 `来源：` 的引用块，这样在面板中修改任务字段时，插件才能把状态、优先级、任务描述、日期和子任务链接同步回任务文档正文。

支持的占位符：

- `{{title}}`
- `{{source}}`
- `{{parent}}`
- `{{project}}`
- `{{status}}`
- `{{priority}}`
- `{{description}}`
- `{{dueDate}}`
- `{{planStart}}`
- `{{planEnd}}`
- `{{childTasks}}`
- `{{childTaskList}}`
- `{{createdAt}}`
- `{{updatedAt}}`

其中 `{{childTasks}}` 会渲染为行内块引用，`{{childTaskList}}` 会渲染为 Markdown 列表。

## 10. 使用建议

- 如果希望“从事项库重建任务索引”能找到任务，请把任务文档保留在事项库范围内。
- 如果手动移动或重命名了任务文档，面板显示异常时可以执行一次重建索引。
- 批量删除任务树前，建议确认思源数据已经同步或备份。
- 插件不会把任务数据发送到外部服务，任务数据保存在思源本地数据和插件数据文件中。
