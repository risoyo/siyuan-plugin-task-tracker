# 思源任务追踪插件

这是一个面向任务闭环管理的思源插件雏形。它会把一个指定文档作为“事项库”根文档，每个任务会创建为事项库下的子文档；如果创建子任务，子任务会成为父任务文档的子文档。

第一版先覆盖这些能力：

- 将当前文档设为事项库；
- 从顶栏、当前文档、选中块创建任务文档；
- 记录状态、优先级、项目、计划时间、截止日期、父任务、来源块；
- 在停靠栏中跟踪未完成任务和已完成任务；
- 打开基础日历视图，并单独列出未登记计划时间的任务。

插件索引数据保存在 `tasks.json` 和 `settings.json` 中。任务元数据也会写入任务文档的自定义属性，方便后续从思源文档反向恢复和追踪。
